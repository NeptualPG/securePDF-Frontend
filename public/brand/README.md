# Gearshift brand assets

- `gearshift-light.svg`: full logo for light backgrounds.
- `gearshift-dark.svg`: full logo for dark or red backgrounds.
- `gearshift-mark.svg`: dark mark for favicons and light surfaces.
- `gearshift-mark-white.svg`: white mark for red or dark surfaces.

The React `Logo` component selects these assets from `/brand/` and supports
full-wordmark and mark-only variants.
